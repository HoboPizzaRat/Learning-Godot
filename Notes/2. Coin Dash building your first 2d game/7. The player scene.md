## Scripting the player
You can see that wacky add scipt option on the scene inspector
![[Kuvakaappaus_20260805_095413.png]]
Select the player node and then click the +script icon to add the script to the player
![[Kuvakaappaus_20260805_095643.png]]
The variables require var keyword for definition.

Export keyword can be used to export variable to be changed from the editors inspector panel itself
- very handy when adjusting properties on the go

cluk cluk duck

```gdscript
extends Area2D

@export var speed = 350
var velocity = Vector2.ZERO
var screensize = Vector2(480, 720)


# Called when the node enters the scene tree for the first time.
func _ready() -> void:
	pass # Replace with function body.


# Called every frame. 'delta' is the elapsed time since the previous frame.
func _process(delta: float) -> void:
	velocity = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
	position += velocity * speed * delta
	position.x = clamp(position.x, 0, screensize.x)
	position.y = clamp(position.y, 0, screensize.y)
	
```
the value delta is basically the given time passed between rendering frames

```
if velocity.length > 0:
		$AnimatedSprite2D.animation = "run"
else:
	$AnimatedSprite2D.animation = "idle"
if velocity.x != 0:
	$AnimatedSprite2D.flip_h = velocity.x < 0
	
```

## Set process
is a function that can enable or disable the processing of the _process() functinon that gets called on every frame.

## Preparing for collisions

**signals** are a way for nodes to send out messages to each other and that way alter each others behaviour. Many nodes have built-in signals.

Add these two lines to the top of the player script
```
signal pickup
signal hurt
```
![[Kuvakaappaus_20260808_094236.png]]

You can click those signals on given object and connect them to whatever other objects in the game just by clicking those signal panels and clicking connect on whatever object you want to connect that signal to.
- remember to toggle "make function" switch on unless you dont want it to create a function.

lets add some shush to the newly creted signal function
```
func _on_area_entered(area: Area2D) -> void:
	if area.is_in_group("coins"):
		area.pickup()
		pickup.emit()
	if area.is_in_group("obstacles"):
		hurt.emit()
		die()
```

## final script
```
extends Area2D

signal pickup
signal hurt

@export var speed = 350
var velocity = Vector2.ZERO
var screensize = Vector2(480, 720)


# Called when the node enters the scene tree for the first time.
func _ready() -> void:
	set_process(true)
	position = screensize / 2
	$AnimatedSprite2D.animatino = "idle"


# Called every frame. 'delta' is the elapsed time since the previous frame.
func _process(delta: float) -> void:
	velocity = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
	position += velocity * speed * delta
	position.x = clamp(position.x, 0, screensize.x)
	position.y = clamp(position.y, 0, screensize.y)
	
	if velocity.length() > 0:
		$AnimatedSprite2D.animation = "run"
	else:
		$AnimatedSprite2D.animation = "idle"
	if velocity.x != 0:
		$AnimatedSprite2D.flip_h = velocity.x < 0
	
func die():
	$AnimatedSprite2D.animation = "hurt"
	set_process(false)


func _on_area_entered(area: Area2D) -> void:
	if area.is_in_group("coins"):
		area.pickup()
		pickup.emit()
	if area.is_in_group("obstacles"):
		hurt.emit()
		die()

```
