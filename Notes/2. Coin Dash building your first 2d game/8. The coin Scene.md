We shall create one coin to rule them all(prefab), and just duplicate it!

Create new scene and give the following structure to it
```
Area2D(named coin)
	AnimatedSprite2D
	CollisionShape2D
```

Then just give the coin the animation, set its scale to 0.4
Add collision of circleshape2d and scale it


## Using groups

We can use as tagging system for nodes, giving them a ability to be triggered on scripts withing the wanted behaviour.

You can just click the root of the coin prefab go to the groups menu and create group called "coins". It will automaticallyo add it to the group but you can also toggle it from the group menu.


## Coin Script

we give da doo!
```
extends Area2D

var screensize = Vector2.ZERO

func pickup():
	queue_free()
```

recall that the pickup function is called by the player script.
queue_free() removes the coin from the memory and frees up space.
- it doesnt delete it immediately but adds it to be deleted.
