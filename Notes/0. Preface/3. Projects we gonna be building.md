## Coin dash
small 2d game that demonstrates how to work with scenes and bit of godot node system. 
- basic navigation on godot editor
- intro to gdscripting

## Space Rocks
Building 2d arcade classing with bit of physics
- intro to physics on godot 
- what nodes are for what etc

## Jungle Jump
2d platformer that involves a side scrolling platform
- kinematic bodies intro
- animation states
- basic level design using tile maps

## 3D Minigolf
Building a fucking minigolf course with introduction to bunch of stuff
- meshes how to import and handle them
- lighting basics
- basic camera control tips and tricks

## Infinite Flyer
Pushing 3D development even further
- dynamic content
- procedural generation 
- 3d techniques etc
