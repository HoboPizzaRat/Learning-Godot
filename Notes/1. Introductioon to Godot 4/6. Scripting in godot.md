## About gdscript
its python 2.0 basically lmao
- dynamically typed
- easy to learn
- similar syntax to python


Example gdscript
```gdscript
extends Sprite2D
var speed = 200

func _ready():
	position = Vector2(100, 100)
	
func _process(delta)
	position.x += speed * delta_
```
some notes before diving into gdscript
- _ready() function gets executed after object is loaded and ready to be used in scene
- _process() function executes between every frame
	- time delta is value of time that has passed between every render frame, needed for time based calculations(we dont wanna do wack shit based on the unrealiable framerate rate)
