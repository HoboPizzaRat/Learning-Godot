## Editor window
![[Kuvakaappaus_20260804_171318.png]]

The yellow part is called the viewport and it shows the game scene and other main focus content

The left side green box is about creating and saving resources on you projects and creating new scene nodes and stuff for the game charactrers
- project file orgnanization
- all project files are relative to the res:// path

The right side green box is about managing different properties of selected nodes and objects on godot editor, you can edit physics properties and signals from example on this side
- inspector, signals etc.

The center red box area is about choosing what will the main viewport show
- scripts
- 2d and 3d scenes
- assetstore for selecting more assets to the game

The right side box is about playing animations, videos, playing the game or simulating scenes etc.
