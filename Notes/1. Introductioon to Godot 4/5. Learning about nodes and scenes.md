Nodes is the main building blocks for creating games on godot.
- they have tree like inheritance and all child nodes are relative to the main node
	- for example when you move the head node the children moves as well in the game etc
- different nodes have different properties allowing to customize node behaviour

Scenes in godot are used to craate organized collections of game objects that you can add.
- kinda like unreal engine prefabs, you can use to create collections that you can reuse multiple times after just creating them once
